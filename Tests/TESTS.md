# Проверки

Из корня проекта в WSL выполните:

```bash
uv sync --locked --extra cpu
uv run --locked --extra cpu python -m pytest -q
```

Тесты создают таблицы и модели во временном каталоге. Сквозная проверка обучает модель одну эпоху, загружает комплект в Flask, запускает пакетный прогноз в XLSX и CSV и сравнивает результаты. Проверяются обе разновидности разделителя CSV, многострочный текст с кавычками и поведение API без модели. Эти проверки подтверждают совместимость компонентов. Качество реальной классификации оценивайте на размеченной контрольной выборке.

`Tests/test_training_data.py` проверяет первый чекпоинт multilabel: одинаковую подготовку CSV/XLSX, списки категорий и нормализацию повторных меток, исключение `review`, неизвестных категорий, конфликтов `no_ads`/`spam`, пустых полей и незавершённых проверок. Проверяется отчёт, неизменность исходного файла и отказ текущего `train.py` от многометочного набора до записи модели. Сквозной тест дополнительно подтверждает, что `review` отсутствует в словаре выходов сохранённой модели. Полное multilabel-обучение этими проверками пока не подтверждается.

`Tests/test_dataset_split.py` проверяет второй чекпоинт: нормализацию Unicode, транзитивную группировку по ID и тексту, исключение всей конфликтующей группы, удаление повторов, отсутствие пересечений и воспроизводимость при фиксированном seed. Проверяется размещение единственного редкого примера в обучении и явное предупреждение об отсутствии этой категории в контрольных частях. Для CSV и XLSX проверяются номера исходных записей после фильтрации, сохранение манифеста и отчёта без текстов, неизменность исходника и отказ от перезаписи существующего каталога. Наборы с менее чем тремя независимыми группами отклоняются. Сквозной тест использует разные тексты и проверяет сохранённый словарь CountVectorizer: слова только из валидации и теста в него не попадают.
